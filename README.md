# Sai Dipak Balkawade | Portfolio

Personal portfolio built with plain HTML, CSS and GSAP (ScrollTrigger). No build step.

Live: https://sai-dipak-portfolio.vercel.app

## Run locally

```bash
python -m http.server 8765
```

Then open http://localhost:8765.

## Structure

- `index.html` markup and content
- `style.css` styles
- `main.js` GSAP animations
- `vendor/` GSAP and ScrollTrigger (3.12.5), served locally
- `img/` project screenshots
